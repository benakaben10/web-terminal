Input

IME mode On for Telex/VNI, Japanese, Chinese, Korean and the like. Off for the lowest latency with a hardware keyboard.
Keyboard suggestions Off by default to win back space: the suggestion strip costs a real band of screen height. Turn it on for more accurate Telex, since that strip is also where the IME shows composing text. iOS has its own switch under Settings → General → Keyboard → Predictive.
Show composing text Previews what the IME has not committed yet
Input bar Optional, off by default. A visible field: compose a line, then press ➤ to send it. Turn it on if tapping the terminal does not open the soft keyboard, which is common on iOS/Safari.

Hotkey bar

Customise any key. The sequence it sends understands \e (ESC), ^C (Ctrl+C), \r, \t, \x1b and so on. For example \e[A is arrow up.
